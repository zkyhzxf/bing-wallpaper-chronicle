## 五、这一轮改了什么

| 主人意见 | 落实 |
|---|---|
| 背景底色黑的太难看 | 全部纯色场景换成**真实壁纸做底**（`photo_bg`：模糊 26px、亮度 0.17、暗角），每个场景固定一张不同图 |
| 羽毛画不好，用现成的 | 改用 OpenTaxa 的**真实羽毛摄影**，去白底、裁边、放大到 1000px、提亮暖调 |
| 翼年代记素材自己找 | 找到小狼与小樱的画面，裁 16:9、压暗后做镜 14 的背景 |
| BGM 声音太小 | 从 ×1.0 提到 ×2.6，侧链压缩从 7:1 收到 3:1，加限幅器；整体响度 +3.1 dB |
| 每日一图效果不明 | 改成 **72 张真实壁纸缩略图网格**，逐格点亮 |
| 「当天的图说」是病句 | 句 17 改「哪一天来的、在哪拍的、怎么写的，都写着」；句 18 改「拍摄地和背后的说明都出来了」 |
| 文案和节奏重优化 | 句 9 去掉"雪山/海"改为「上周看过的那张 / 去年冬天那张」；句 26 拆成两句（三天写出来 / 代码全在 GitHub），多出一个镜头 |
